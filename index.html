Retrieval Pipeline
Transcripts split into chunks, embedded with text-embedding-3-small in batches of 128, stored in FAISS IndexFlatL2. Top-k=5 retrieved then reranked before grounded response generation.
Chunking & Timestamp Alignment
Character-based chunking (1000/200 overlap) with each chunk tracking source timestamps. Enables clickable jump-to-timestamp evidence links in the Chrome MV3 extension.
Retrieval & Reranking
FAISS retrieves 3× oversampled candidates. Hybrid reranker scores by semantic similarity + keyword overlap, filters to top-5.
Prompt Orchestration & Grounding
Evidence injected into structured prompt for GPT-4o-mini. Answer / Confidence / Follow-up format. Hallucination structurally constrained.
Extension & Backend
FastAPI with asyncio.Lock guarding FAISS mutations. Chrome MV3 renders evidence cards with click-to-seek timestamps.
Design Philosophy
A systems project first — not a chatbot wrapper. Every decision was made to make retrieval robust and responses trustworthy.

Vision-Language Architecture
Dual-branch design processes image and text independently before fusion. The 3D U-Net encoder extracts volumetric features from FLAIR MRI (128³, BraTS 2020), while clip-vit-base-patch32 encodes 344 paired TextBraTS radiology reports into semantic feature representations. Both modalities are unified at the cross-attention fusion layer.
Cross-Attention Fusion
Image features become queries; text features become keys and values. Clinical language — lesion location, edema extent, necrosis indicators, ventricular compression — contextually modulates spatial encoder attention. Residual connections and LayerNorm stabilise training.
3D Segmentation Pipeline
Volumetric 128³ processing preserves full spatial context. The encoder-decoder with skip connections recovers fine spatial detail. The 4-channel output mask distinguishes background, necrotic core, peritumoral edema, and enhancing tumor in a single forward pass.
Training & Optimization
AdamW with lr=5e-5 and ReduceLROnPlateau. Combined Dice Loss + BCEWithLogits. Mixed precision training. Early stopping (patience=5) halted at epoch 5 — the best validation checkpoint.
Explainability & Validation
Three complementary explainability pathways: (1) Grad-CAM over bottleneck activations — red zones correspond to predicted tumor boundaries; (2) t-SNE of MRI, text, and fused embeddings confirms the cross-attention fusion creates a distinct, separable multimodal representation space; (3) Dice score distribution across all 86 validation volumes shows zero cases below 0.90 — no catastrophic failure modes.

Temporal Sequence Modeling
Network flows encoded as sliding-window sequences (length 10). Shuffled-sequence ablation confirms the model learns coherent temporal patterns — order is the signal.
Transformer Attention Architecture
MultiHeadAttention (4 heads, key_dim=64) over sequence dimension. Residual connections + LayerNorm stabilise training. GlobalAvgPool1D aggregates the full sequence before classification.
Explainability System
Attention heatmaps per class + SHAP TreeExplainer on Random Forest baseline for global feature attribution and learned-representation verification.
Multiclass vs Binary Detection
CICIOT23: 10-class softmax across DDoS subtypes, DoS variants, Mirai floods, DNS spoofing. TON-IIoT: binary sigmoid — independent preprocessing, scaling, and evaluation pipelines.
Research Ablation Studies
Window-size ablation (5 vs 10) and sequence-order ablation (shuffled) isolate temporal coherence contribution. Random Forest baselines establish performance ceilings.
Research Positioning
Temporal coherence is a first-class signal for intrusion detection. Attention explainability bridges high-accuracy detection and trustworthy AI for IIoT security.

Custom Binary Protocol
Struct-packed header with message type, sender ID, payload length, and checksum — enabling multiplexed communication over a single socket.
TCP/UDP Hybrid Transport
Chat and files use persistent TCP. Audio, video, and screen frames use UDP for minimal latency — tolerating occasional dropped frames gracefully.
Concurrent Client Handling
Each connection spawns a dedicated thread. Lock-guarded client registry manages up to 20 active connections with broadcast routing and timeout eviction.
Media Packetisation
OpenCV frames JPEG-compressed before UDP dispatch. PyAudio chunks packed into fixed-size datagrams. Receiver reconstructs in real-time with a frame buffer.
